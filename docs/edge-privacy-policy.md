# 小红书 · 企业微信外观 — Microsoft Edge 扩展隐私政策

最后更新日期：2026 年 10 月 15 日

适用版本：扩展 0.1.0（皮肤 0.6.6）。

## 1. 扩展用途

本扩展为 Microsoft Edge 中的小红书桌面网页版提供企业微信风格的界面。
主要功能包括导航和列表布局、笔记与评论的展示、颜色模式及皮肤开关。
本扩展是非官方作品，与小红书、腾讯或企业微信不存在官方关联，
不提供企业微信聊天、邮件、会议或其他办公服务。

## 2. 在本地访问和处理的信息

为实现用户可见的界面，本扩展访问当前小红书页面已经加载的内容及原生组件数据，包括：

- 笔记和评论中的文字、图片或视频引用、链接、标题、时间及页面自带的元信息。
- 当前账号、笔记作者及已加载评论参与者的昵称、头像、用户 ID 和个人主页链接。
- 列表中笔记的标识及原生导航参数，用于打开笔记、去重、保持列表和委托原生加载。

这些信息用于在当前浏览器页面中呈现界面，或在当前页面的内存中暂存以保持交互状态。
本扩展不将上述网页内容写入扩展的持久设置存储，也不将其发送给开发者服务器。

切换笔记或导航前，扩展会在本地判断评论输入框是否含有未发送的文字，
以便提示用户是否继续离开。扩展不会记录、持久保存或向开发者上传评论草稿。
扩展不读取小红书私信或聊天记录。

扩展响应点击、滚动和部分键盘事件来实现导航、分页和菜单控制，
不生成用户点击、鼠标、滚动或按键行为日志，不使用这些操作建立用户画像。
扩展不调用设备定位 API，不推断用户位置，也不读取浏览器历史记录。

## 3. 保存的设置

本扩展通过 Microsoft Edge 的 `chrome.storage.local` 仅持久保存：

- 皮肤是否启用。
- 颜色模式：浅色、深色或跟随系统。

设置在同一浏览器配置文件下的扩展弹窗和小红书标签页之间保持一致，
不由本扩展上传到开发者服务器。扩展不使用 `chrome.storage.sync` 提供云端设置同步。

## 4. 登录与网站通信

登录、搜索、笔记分页、内容加载、评论发送及其他原生操作由小红书自身处理。
扩展不读取或保存用户密码、登录 Cookie 或登录凭据，不代替用户完成扫码登录。

呈现原生头像或媒体、打开笔记以及委托原生加载时，浏览器仍可能与小红书及其内容分发服务通信。
这些网站请求由用户的原生网站会话或原生资源地址完成；小红书自身的数据处理适用其隐私政策。
本政策不替代小红书或 Microsoft Edge 自身的隐私说明。

## 5. 向第三方提供数据

本扩展不包含开发者运营的数据接收服务器，不包含广告、分析统计、遥测或第三方追踪 SDK。
开发者不会通过本扩展出售用户数据，也不会将用户数据用于与换肤功能无关的目的、
信用评估或借贷决策。

## 6. 用户控制

用户可以在扩展弹窗或页面内的外观设置中切换皮肤和颜色模式。
关闭皮肤会恢复原生视图，不会自动发送或删除未发送的评论草稿。
用户也可以通过 Microsoft Edge 扩展管理页面停用或卸载扩展，
并刷新已经打开的小红书网页以移除页面中已运行的皮肤。
卸载扩展会移除本扩展的本地设置。

## 7. 政策更新

如果后续版本改变数据访问、保存或使用方式，开发者将同步更新本政策及商店披露。
本政策不授权与所述功能无关的数据处理。
